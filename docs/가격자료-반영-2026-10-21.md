# 피부시술 가격자료 반영 기록

반영일: 2026년 10월 21일

## 자료와 범위

- 사용자가 제공한 `붙여넣은 텍스트.txt`를 원문 그대로 `docs/제공가격자료-2026-10-21.txt`에 보관했다.
- 본문 가격 목록 68개를 용량·샷수·국산/수입·회차·구성별로 나눠 78개 규격, 51개 시술군으로 정리했다. 뒤에 반복된 표는 별도 표본으로 세지 않았다.
- 숫자 단위는 만원이다. 가격 범위와 원문 제공 평균을 그대로 보관하며, 평균이 없는 항목은 `null`로 둔다.
- 원문이 주장한 이미지 75건과 공개 시세 교차 검증은 이번 작업에서 확인한 사실이 아니다. 원본 이미지를 연결하거나 병원 가격을 새로 조사하지 않았다.
- 부가세는 원문이 설명하는 10% 별도 기준을 안내하되, 개별 가격표의 실제 포함 여부는 미확인이다.
- 본문과 반복 표가 다른 경우 본문 규격을 우선했다. 온다 80~100KJ, 슈링크 500~600샷, 포텐자 모공·나비존을 임의로 100KJ·600샷·풀페이스로 바꾸지 않았다.

## 앱 연결

- `data/시술-표준가격-2026-10.json`: 원문 출처·검증 상태와 규격별 가격.
- `lib/시술표준가격.ts`: 정확한 시술명·별칭으로 조회한다. 리쥬란 힐러/HB/아이, 쥬베룩 스킨/볼륨처럼 다른 제품은 섞지 않는다.
- `/prices`: 전체 표준규격 참고 가격과 기존 강남권 공개 가격 집계를 각각 표시한다.
- `/prices/[treatment]`: 규격별 표와 기존 집계를 표시하며 새 시술도 직접 열 수 있다. 사이트맵에 새 시술 경로를 추가했다.
- `/treatment/[id]`: 대응하는 시술의 규격별 참고 가격을 표시한다.
- `/api/chat`: 가격 질문에 새 규격별 자료를 우선 참고하고, 규격이 모호하면 조건을 확인하도록 연결했다.

## 기존 데이터와의 관계

기존 이미지 근거 15소스·125행, 중위값 집계, 시술 마스터의 가격 범위와 추천 점수 계산은 유지했다. 요약 가격을 원시 관측값으로 넣어 근거 수나 중위값을 부풀리지 않는다. 새 참고표는 Supabase의 기존 집계 유무와 관계없이 코드에 포함된 데이터에서 표시된다.

Supabase에 SQL을 실행하거나 GitHub로 푸시·운영 배포한 작업은 이 반영에 포함되지 않는다.

## 검증

데이터 검증: `node scripts/시술표준가격-검증.mjs`

변경 파일 ESLint와 TypeScript 검사를 통과했다. 운영 빌드는 메모리 사용을 줄이기 위해 임시 작업본에서 작업 수를 1개로 제한해 전체 104개 페이지 생성을 완료했다. 빌드용 설정은 검증 후 원래대로 되돌렸다.

로컬 HTTP 응답으로 목록 78개 규격, 51개 시술군 전체 상세의 규격·가격 범위·제공 평균과 사이트맵 경로를 확인했다. 별도 대조에서도 본문 68개 항목과 가격 값의 불일치가 없었다. 운영 인증정보나 실제 AI 호출은 검증에 사용하지 않았다. 브라우저 시각 검사는 연결 제한으로 완료하지 못했다.
