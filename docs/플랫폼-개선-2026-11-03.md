## 반영 내용

- 제공된 두 추천문의 중복을 합쳐 서울 25개 분야를 전부 구조화했습니다. 피부 시술 14, 성형·모발 9, 체형·경락 2개입니다.
- 시술·병원·원장·별칭 검색, 분야·상태 필터, 브라우저 저장, 검색/단일 항목 공유, 공유 실패 시 수동 복사, 원문 펼치기를 구현했습니다.
- 이름·현재 소속·위치·장비 전언은 확인 범위를 표시했습니다. 데이터 부족 3개와 비공개 1개도 보존했고 이름이나 소속을 임의로 채우지 않았습니다.
- 홈을 서울 경험 추천과 가격 비교 중심으로 개편하고 가격 상세·추천 결과·전체 푸터에서 연결했습니다.
- 한국어 추천 질문에 섞인 중국어를 제거하고 예산 상한/가격 중간값 설명, 실패 시 답변 유지와 재시도, 요청 취소, 모바일 설문 길이를 개선했습니다.
- 추천 엔진은 관심사·회복 조건을 필터링하고 후보의 등록 가격 상한 합계가 예산 이내가 되도록 수정했습니다. AI가 시술·가격을 임의로 덮어쓰는 경로를 제거했습니다.
- 챗 안내는 등록된 경험·시술·가격 자료를 찾습니다. 외부 AI 전송을 제거했고 이미지 API는 본문을 읽지 않고 비활성 응답을 반환합니다.
- 이메일로 타 사용자 요청을 조회하는 구조를 사용자 ID 기반 서버 조회로 바꾸고 병원센터 승인 검증, OAuth 복귀 경로, 폼 검증, 중복 전송·오류 대응을 보강했습니다.
- 실제 제휴처처럼 보이던 예약 예시를 상담 준비 안내로 바꿨습니다. 예약 확정을 제공한다고 표시하지 않습니다.
- 환경변수 없이도 공개 화면을 볼 수 있게 했고, 카테고리 DB 실패 시 로컬 자료를 표시하며 로컬 시술 ID 상세가 동작하도록 수정했습니다.
- 언어 저장 차단 시 오류, 초기 서버/클라이언트 언어 불일치, 키보드 포커스와 모션 접근성을 보완했습니다.

## 보존과 범위

실제 소스의 당시 미커밋 변경을 포함한 73개 파일을 먼저 작업본에 복사했습니다. .git, .next, node_modules, .vercel, 실제 .env, Supabase 연결 캐시·인증정보는 복사하지 않았습니다. 의존성은 원본 node_modules를 연결해 사용했습니다. 수정 전 파일 해시는 작업 폴더 상위의 탱글-수정전-파일목록.json에 보관했습니다.

기존 78개 규격 가격표와 51개 시술군, 원본 가격 근거와 미기재 평균은 그대로 유지했습니다. 원본의 기존 사용자 작업 중 이번 수정과 겹치지 않는 파일은 보존합니다.

## 현재 한계와 배포

병원명·원장 현 소속·장비 운영·내돈내산 지출은 외부 검증하지 않았습니다. 운영 DB RLS와 실제 카카오 로그인·견적 제출은 인증정보를 사용하지 않아 검증하지 않았습니다.

자동 승인 검토가 입력·사진의 OpenAI 전송 변경을 거절했습니다. 구체적인 전송 대상과 payload 승인이 없다는 사유였습니다. 이번 구현은 외부 전송을 제거해 진행했습니다. 이미지 분석을 다시 제공하려면 전송할 내용·목적지·용도에 대한 별도 승인과 처리가 필요합니다.

견적 연결은 DB 정책 검증 후 명시적 설정 전까지 비활성입니다. 상세 내용은 접근권한 점검 문서에 있습니다. 이 코드 검증이 실제 예약, 병원 제휴, 의료 적합성 검증을 뜻하지 않습니다.

위 검증은 로컬 개선 단계의 기록입니다. 후속 GitHub 푸시와 tangle.kr 운영 배포 상태는 이어지는 작업 결과를 확인합니다.
